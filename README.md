# PR TECH 공장 신축공사 3D (브랜드 VIDAN 비단)

DWG 도면(건물배치도·평면도·입면도·단면도)을 바탕으로 만든 웹 3D 모델입니다.

- 주동 2개 동: 150 × 25 m, 처마 11.0 m / 최고 13.6 m (X1–X4 구간 15.0 / 17.6 m)
- 부1동: 23 × 11 m, 지상 3층 (층고 3.6 m 가정) — 클릭하면 층별 내부·가구 보기
  - 1층 식당(126석)·주방·접견실·방·화장실 / 2층 사무실·휴게실 / 3층 회의실·방 5실·샤워장·탈의실·보일러실
- 동당 호이스트 크레인 4대 (3t ×2, 2t ×2), 행가도어 5.0 × 5.0 m 2개소
